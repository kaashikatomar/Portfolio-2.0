# Kaashika Tomar — Portfolio

A responsive, static portfolio website built with HTML, CSS and vanilla JavaScript.

## Run locally

No build step or package installation is needed.

1. Open this folder in VS Code.
2. Open `index.html` in a browser, or use the free **Live Server** extension if you already have it installed.
3. If you do not have Live Server, double-click `index.html` in Finder to preview it.

## Publish

This project can be hosted as a static website using GitHub Pages or Vercel.
