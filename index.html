04 — LEARNING IN THE OPEN

Open-source journey.

My S&AI course introduced me to the structure of an existing open-source project and the workflow of contributing to one.

⌘

S&AI COURSE PROJECT · SQLITE

Exploring the SQLite exercise repository

Our main System & AI course project was based on the SQLite repository. We were assigned ten different tasks, working through them with Antigravity as an AI-assisted development tool. The larger goal was to understand how open source works: navigating an existing repository, reading its structure and documentation, understanding task requirements, making changes and learning the contribution workflow.

This was an introduction to contributing within an established codebase rather than building everything from scratch. The experience helped me become more familiar with repository organisation, task-based development and GitHub collaboration.
